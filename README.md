# Retail Inventory System Rollout | IT Project Management Portfolio

**Type:** Simulated IT implementation case study (not an actual Nintendo or employer project)  
**Role:** Project Manager (simulation)  
**Schedule:** November 2, 2026–January 4, 2027 (illustrative)  
**Tools:** Excel, project documentation, risk register, milestone tracker

## Scenario
A fictional mid-sized retailer uses disconnected spreadsheets for store and warehouse inventory. The proposed solution is a centralized inventory platform that supports SKU tracking, stock thresholds, receiving, and e-commerce inventory synchronization. This portfolio project demonstrates how an IT project manager would plan, coordinate, monitor, and report on the rollout. It does **not** claim a production implementation or measured business results.

## Deliverables
- `Retail_IT_Project_Tracker.xlsx`: Editable project dashboard, 18-task tracker, risk register, milestone plan. KPI formulas update from task statuses.
- `Project_Charter.md`: Objectives, scope, stakeholder roles, timeline, and success criteria.
- `Weekly_Status_Report.md`: Sample leadership update and decision requests.
- `Meeting_Notes_and_Action_Log.md`: Sample meeting agenda, notes, and assigned follow-ups.
- `Change_Log.md`: Scope-change assessment template and example.

## How to use
1. Open the Excel workbook and inspect the **Dashboard** sheet.
2. Change task statuses in **Task Tracker** to see completion rate and status counts update.
3. Update **Risk Register** to reflect mitigations and owners.
4. Compare milestones against project progress; use the status report and action log for leadership communication.
5. All statuses and dates are **fictional examples**, not a record of completed work.
